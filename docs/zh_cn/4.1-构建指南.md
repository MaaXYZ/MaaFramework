# 4.1 构建指南

> [!TIP]
> _仅当您准备开发 MaaFramework 本身时，才需要阅读本章节内容。若您仅希望基于 MaaFramework 开发自己的应用，则请参考 [快速开始](1.1-快速开始.md)。_

开始前，请确保已安装 Git、Python 3、CMake 3.24+，以及对应平台的编译链（Windows: MSVC 2022；Linux/macOS: Ninja + g++/clang）。

## 本地开发

1. 完整克隆本仓库及子模块（推荐一次性同步）  
    子模块包含第三方依赖，构建前必须初始化，可重复执行以保证同步。

    ```sh
    git clone --recurse-submodules https://github.com/MaaXYZ/MaaFramework.git
    ```

    或

    ```sh
    git clone https://github.com/MaaXYZ/MaaFramework.git
    cd MaaFramework
    git submodule update --init --recursive
    ```

2. 下载 MaaDeps prebuilt

    ```sh
    python3 tools/maadeps-download.py
    ```

    脚本会自动下载并校验预编译依赖，如遇网络问题可重复执行。

3. 配置 CMake 预设

    - Windows

    ```bash
    cmake --preset "MSVC 2022"
    ```

    - Linux

    ```bash
    # 根据实际情况择一执行
    cmake --preset "NinjaMulti Linux x64"
    # 或者
    cmake --preset "NinjaMulti Linux arm64"
    ```

    - macOS

    ```bash
    cmake --preset "NinjaMulti"
    ```

4. 构建并安装

    ```bash
    cmake --build build --config Release
    cmake --install build --prefix install
    ```

根据需要可将 `--config` 切换为 `Debug`/`RelWithDebInfo`。生成的二进制及相关文件默认位于 `install` 目录。

详情请参考 [Build CI](https://github.com/MaaXYZ/MaaFramework/blob/main/.github/workflows/build.yml) 。

## Android 主机的 iOS 视频流

Android arm64 主机可通过 FFmpeg 软件解码使用 iOS `Stream` 取图；当前不使用 MediaCodec。
未提供目标平台 FFmpeg 时仍可只构建 `ScreenshotService`。发现接口按共享协议目标的实际编译能力返回取图方法。

先准备 Android NDK、arm64 Android MaaDeps 和 `make`，从仓库根目录构建额外依赖：

```bash
export ANDROID_NDK_ROOT=/path/to/android-ndk
export ANDROID_API=24
export WORK_DIR="$PWD/build/android-deps/src"
bash tools/ios-android-deps.sh -j 6 "$PWD/build/android-deps/out"
```

脚本固定下载并校验 OpenSSL、curl 和 FFmpeg 源码；FFmpeg 只启用 HEVC/PNG 解码与像素转换，
生成 `libavcodec.so`、`libavutil.so`、`libswscale.so`。不启用 GPL/nonfree 组件。
源归档保存在 `WORK_DIR`，FFmpeg 构建记录及许可证保存在输出前缀的 `share/ffmpeg/`。

配置已有 Android 构建时，传入脚本打印的 OpenSSL/curl 路径，并额外指定：

```bash
cmake -S . -B build/android/arm64-v8a \
    -DWITH_IOS_CONTROLLER=ON \
    -DMAA_IOS_FFMPEG_INCLUDE_DIR="$PWD/build/android-deps/out/include" \
    -DMAA_IOS_AVCODEC_LIBRARY="$PWD/build/android-deps/out/lib/libavcodec.so" \
    -DMAA_IOS_AVUTIL_LIBRARY="$PWD/build/android-deps/out/lib/libavutil.so" \
    -DMAA_IOS_SWSCALE_LIBRARY="$PWD/build/android-deps/out/lib/libswscale.so"
cmake --build build/android/arm64-v8a --config Debug --parallel 6
cmake --install build/android/arm64-v8a --config Debug --prefix build/android-install
```

首次配置仍需指定 NDK toolchain、`ANDROID_ABI=arm64-v8a`、`ANDROID_PLATFORM=android-24`
及 `MAADEPS_TRIPLET=maa-arm64-android`。运行包需包含 MaaFramework/MaaDeps 运行库和三个 FFmpeg 共享库；
使用此脚本的 FFmpeg 时，安装步骤会复制三个共享库与构建记录、许可证。
这条配方当前只支持 arm64，其他 ABI 需要各自构建依赖。手机端集成还需具备局域网访问权限；
软件解码的 CPU 占用、发热及持续帧率应在目标 Android 设备上评估。
