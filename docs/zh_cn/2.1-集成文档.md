### 资源加载诊断

`MaaResourceGetLoadDetail(resource, res_id, buffer)` 查询一次已完成加载的 JSON 快照。Python 为 `resource.get_load_detail(res_id)`，Node.js 同名。返回值表示是否找到快照，加载是否成功由快照的 `status`（现有 `MaaStatus`）表示。未知、未完成和已清理的 ID 返回 false / None / null。`MaaResourceClear` 成功时清理这些记录。

快照包含 `res_id`、`path`、`type`、`hash`、`status`、`errors`。终态回调发出前快照已保存；终态回调的 JSON 与查询结果相同。每次加载有独立记录，后续加载不会覆盖之前的诊断。

`errors` 为对象数组，`code` 是稳定的机器可读标识。当前包括 `path_not_found`、`json_read_failed`、`invalid_pipeline_root`、`empty_node_name`、`duplicate_node`、`invalid_node`、`node_reference_not_found`、`invalid_regex`、`inference_backend_unavailable`、`load_failed`。`json_read_failed` 表示文件读取或 JSON/JSONC 解析失败，不能单凭该代码区分二者；底层未提供具体原因时使用 `load_failed`。

诊断仅在来源已知时提供 `file`、`node`、`pointer`、`field`、`target`。`pointer` 使用 JSON Pointer 转义，缺失引用定位到声明 `next` / `on_error` 的字段；继承的字段指向原始文件，运行时覆盖后不猜测源位置。此接口不改变既有加载、校验或部分加载失败的行为，也不保证列出所有错误。
